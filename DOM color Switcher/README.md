# DOM color Switcher

A simple DOM project built using HTML, CSS, and JavaScript.

## Features

- Change background color on click
- Uses DOM selectors
- Uses Event Listeners
- Beginner-friendly project
- Responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript (DOM)

## Concepts Practiced

- document.querySelectorAll()
- addEventListener()
- Event Handling
- DOM Manipulation
- CSS Styling
